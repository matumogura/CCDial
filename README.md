# CCDial プライバシーポリシー

最終更新日: 2026年10月6日（v1.13.0）

## 概要

CCDial（以下「本拡張機能」）は、有志が個人で作った非公式の拡張機能です。
ココフォリア（ccfolia.com）の運営・開発元とは関係がなく、提携や承認も受けていません。

CCDial（以下「本拡張機能」）は、ユーザーの個人情報を収集、送信、共有、販売しません。
本拡張機能はネットワーク通信を一切行わず、すべての処理がユーザーのブラウザ内で完結します。

## 本拡張機能が保存する情報

本拡張機能は、ユーザーが `https://ccfolia.com/rooms/` で始まるページを開いた際に、
以下の情報をユーザーのブラウザ内（`chrome.storage.local`）に保存します。

**ルームの記録（最大 12 件）**

- ルーム ID とルーム URL
- ルーム名（ページ左上に表示されている文字列）
- ユーザーが手動で設定した表示名（設定した場合のみ）
- そのページのスクリーンショット（横 640 ピクセルに縮小した JPEG 画像）
- ピン留め・スクリーンショット据え置きの状態、ピン留めの並び順、記録日時
- ユーザーが手動で登録した関連ページの URL とラベル（登録した場合のみ）

12 件を超えると、ピン留めされていないものから古い順に削除されます。

**履歴（最大 300 件）**

- ルーム名・ルーム URL・訪問日時

履歴にスクリーンショットは含まれません。300 件を超えると古い順に削除されます。

**表示の設定**

- この画面を新しいタブに出すか、ツールバーのボタンからのみ開くか
- 「ボタンからのみ」を選んだ場合に、新しいタブの代わりに開くページの URL（入力した場合のみ）
- 表示言語（自動 / 日本語 / 英語 / 韓国語 / 簡体字中国語 / 繁体字中国語）
- 配色（端末に合わせる / ライト / ダーク）
- 一覧の並べ方（ゆったり / 1 画面に収める）

いずれも選択結果を表す短い文字列のみで、個人を識別できる情報は含みません。

関連ページの URL は、ユーザーが編集画面に自分で入力したものだけを保存します。
ローカルファイル（file://）を指定した場合も、その文字列を保存するだけで、ファイルの中身は読み取りません。
本拡張機能が閲覧履歴やブックマークを読み取ることはありません。

### バックアップの書き出しについて

設定画面から、上記の保存内容をまとめて 1 つの JSON ファイルとして書き出せます。
これはユーザーが操作した時に、ユーザー自身の端末へファイルを保存するだけの機能です。
書き出したファイルが外部へ送信されることはありません。
読み込む時は、件数の内訳を表示して確認を挟んだうえで、現在の記録を置き換えます。

## 保存場所と送信について

- 上記の情報は、ユーザーのブラウザのローカル ストレージにのみ保存されます
- 開発者を含む第三者が、この情報にアクセスすることはできません
- 外部のサーバーへの送信は一切行いません
- 解析ツール、トラッキング、広告配信は一切使用していません
- Chrome の同期機能は使用していないため、他の端末に転送されることもありません
- 外部スクリプトの読み込み、`eval`、リモート設定の取得は行いません。
  画面の文言や配色を含むすべてのコードとリソースは、拡張機能のパッケージに同梱されています
- 表示言語の切り替えに外部の翻訳サービスは使用しません

## スクリーンショットの撮影範囲

スクリーンショットを撮影するのは、次の条件をすべて満たす場合のみです。

- 手前に表示されているタブの URL が `https://ccfolia.com/rooms/` で始まる
- そのタブがウィンドウ内でアクティブである

他のウェブサイトを表示している間に撮影されることはありません。
また、コンテンツ スクリプトが読み込まれるのは `ccfolia.com` のみです。

タイルの鍵ボタン（スクリーンショットの据え置き）を押したルームでは、以後の撮影を行いません。

## 権限について

インストール時に必須で要求する権限は次の 2 つだけです。

- `https://ccfolia.com/*` へのアクセス（ルーム名と URL の取得）
- `storage`（ブラウザ内への保存）

スクリーンショットの撮影に使う `chrome.tabs.captureVisibleTab()` API は、
Chrome の仕様上「すべてのサイト」へのアクセス権（`<all_urls>`）または `activeTab` を必要とします。
ホスト権限にパスを指定しても Chrome 側で無視されるため、`https://ccfolia.com/rooms/*` のように
対象を絞った指定では撮影できません。また `activeTab` は拡張機能アイコンを押した直後にしか
有効にならないため、自動記録には使用できません。

そのため本拡張機能では `<all_urls>` を**任意の権限（optional_host_permissions）**として宣言し、
新しいタブ画面の「スクリーンショットを有効にする」ボタンを押した時にのみ要求します。

- インストール時に「すべてのサイト」の警告は表示されません
- 許可しない場合でも、ルーム名と URL の記録は動作します
- 許可した後も、この権限は上記 API の呼び出しにのみ使用し、
  他のウェブサイトのページ内容の読み取りや改変は行いません
- 許可は `chrome://extensions` → CCDial → 詳細 → 「サイトへのアクセス」から
  いつでも取り消せます

## 記録の削除方法

- 個別のタイル: 一覧でタイルにマウスを乗せ、× ボタンを押してください
- 関連ページ: タイルの 🔗 ボタンから、行ごとに × で削除できます
- 履歴: 履歴ページで 1 件ずつ、または「全削除」でまとめて削除できます
- すべての記録: `chrome://extensions` から本拡張機能を削除すると、保存された情報もすべて削除されます
