# Ccfolia Dial プライバシーポリシー

最終更新日: 2026年8月18日（v1.3.0）

## 概要

Ccfolia Dial（以下「本拡張機能」）は、ユーザーの個人情報を収集、送信、共有、販売しません。
本拡張機能はネットワーク通信を一切行わず、すべての処理がユーザーのブラウザ内で完結します。

## 本拡張機能が保存する情報

本拡張機能は、ユーザーが `https://ccfolia.com/rooms/` で始まるページを開いた際に、
以下の情報をユーザーのブラウザ内（`chrome.storage.local`）に保存します。

- ルーム ID とルーム URL
- ルーム名（ページ左上に表示されている文字列）
- ユーザーが手動で設定した表示名（設定した場合のみ）
- そのページのスクリーンショット（横 640 ピクセルに縮小した JPEG 画像）
- ピン留めの状態、記録日時

保存される件数は最大 12 件です。12 件を超えると、ピン留めされていないものから古い順に削除されます。

## 保存場所と送信について

- 上記の情報は、ユーザーのブラウザのローカル ストレージにのみ保存されます
- 開発者を含む第三者が、この情報にアクセスすることはできません
- 外部のサーバーへの送信は一切行いません
- 解析ツール、トラッキング、広告配信は一切使用していません
- Chrome の同期機能は使用していないため、他の端末に転送されることもありません

## スクリーンショットの撮影範囲

スクリーンショットを撮影するのは、次の条件をすべて満たす場合のみです。

- 手前に表示されているタブの URL が `https://ccfolia.com/rooms/` で始まる
- そのタブがウィンドウ内でアクティブである

他のウェブサイトを表示している間に撮影されることはありません。
また、コンテンツ スクリプトが読み込まれるのは `ccfolia.com` のみです。

## 権限について

インストール時に必須で要求する権限は次の 2 つだけです。

- `https://ccfolia.com/*` へのアクセス（ルーム名と URL の取得）
- `storage`（ブラウザ内への保存）

スクリーンショットの撮影に使う `chrome.tabs.captureVisibleTab()` API は、
Chrome の仕様上「すべてのサイト」へのアクセス権（`<all_urls>`）または `activeTab` を必要とします。
ホスト権限にパスを指定しても Chrome 側で無視されるため、`https://ccfolia.com/rooms/*` のように
対象を絞った指定では撮影できません。また `activeTab` は拡張機能アイコンを押した直後にしか
有効にならないため、自動記録には使用できません。

そのため本拡張機能では `<all_urls>` を**任意の権限（optional_host_permissions）**として宣言し、
新しいタブ画面の「スクリーンショットを有効にする」ボタンを押した時にのみ要求します。

- インストール時に「すべてのサイト」の警告は表示されません
- 許可しない場合でも、ルーム名と URL の記録は動作します
- 許可した後も、この権限は上記 API の呼び出しにのみ使用し、
  他のウェブサイトのページ内容の読み取りや改変は行いません
- 許可は `chrome://extensions` → Ccfolia Dial → 詳細 → 「サイトへのアクセス」から
  いつでも取り消せます

## 記録の削除方法

- 個別のタイル: 新しいタブ画面でタイルにマウスを乗せ、× ボタンを押してください
- すべての記録: `chrome://extensions` から本拡張機能を削除すると、保存された情報もすべて削除されます
